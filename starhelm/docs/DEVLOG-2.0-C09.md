## 内容
- 素材:Stellarium skycultures「western」在当前仓库已改名 **modern**(路径 skycultures/modern/,提交 210b7cc)。85 幅插画(Pup/Ser/Vel 无图,船底座用整幅南船座 argonavis)→ 灰度 WebP x/constart/,共 446 KB;手机版 x/constart/s/(仅原图 512 px 的 31 幅缩到 256 px)104 KB。许可原文 x/vendor/FAL-1.3.txt,登记见 x/LICENSES.md。
- 数据 x/sh-x-constart-data.js(17.6 KB,docs/build/build_constart.py 生成):88 星座 [缩写, 拉丁名, 中文名, 文件, 宽高, 手机版, 3 锚点 [px,py,X,Y,Z 光年], 标签系数]。锚星直接存 HYG v4.1 的 J2000 3D 坐标(不走站内序号——很多锚星不在 sh-stars-data.js 的 4,268 颗里)。无插画的 3 个星座取相距最远的 3 颗连线星作标签锚点。
- 对齐 x/sh-x-constart.js(SHXCA):与 Stellarium 同法——像素 → 3 锚星当前方向张成的平面(仿射,3 点精确)→ 归一化到天球 r=880;每幅 8×8 网格,加法混合、不透明度 0.34、色调 #c2cff0(星辉银偏靛)。标签位于连线星方向重心,中文 + 拉丁名。
- K 键三档(sh-x-deep.js):连线 → 连线 + 插画 → 关(手机底部按钮条新增「星座」,操作说明补 K)。未按过 K 时保持旧行为(穿越日球层顶后连线自动淡入);按过 K 后连线、标签在太阳系内也显示。SHXD.mode()/cycle()/lf() 为新接口,SHXD.lines() 保持兼容。
- 视差:选「重算」——锚星方向随飞船位置实时重算,与连线同一套 HYG 坐标,太阳系内即无穷远天球。锚星三角形相对从太阳看的边长比变形 >12% 开始淡出、>35% 全隐,离任一锚星 <0.5 光年隐去(古典星图那时已无意义;连线仍保留实际 3D 变形)。例:在天狼星旁(8.3 光年)猎户座插画隐去(锚星 χ1 Ori 仅 28 光年),大犬、大熊座保留。
- 性能:首次进入「插画」档才加载,按与视线夹角就近排队,同时最多 5 张(手机 3 张);手机(短边 <700 或内存 <4 GB)用 256 px 版。「减少动态」时开关不做淡入淡出。
- **顺带修正(判断)**:自测发现驾驶舱星空贴图与 HYG/行星坐标差 180° 赤经(看向猎户座时出现银心)。原因:NASA SVS Deep Star Maps 以 0h 为图像中心,SHFX3D.skyMesh 的球面 UV 把 0h 放在接缝。已在 sh-x-deep.js 只对驾驶舱天空球绕赤道极轴转 180°;修正后天狼、参宿四、参宿七、南河三、毕宿五都落在贴图亮星上,太阳方向与真实赤经吻合(差 0.7°,为估算误差)。1.0 共用的 sh-fx3d.js 未改——1.0 太阳系/母港场景可能有同样偏差,待总指挥决定是否在 1.0 修。
