## 2. 跃迁不出帧:查清并修复
- 诊断脚本 work/gj_diag.py(SwiftShader 1440×900,量 3 s 内 rAF):
  - 原版:平时 0.8 fps,跃迁中 0.6 fps,截图 30 s 超时;
  - 只关隧道画布:0.2 fps(更差,镜头贴近盘面);
  - 只关银河粒子场景:3.3 fps,截图 2.5 s。
- 结论:元凶是银河粒子近盘过度绘制(镜头在 1.4–2.2 万光年处沿盘面移动),不是隧道画布。
- 修复:sh-x-galaxy.js 新增 `skip3d` 钩子,隧道遮挡度 ≥ 0.985 时跳过 `rd.render`(隧道全屏不透明,看不到银河);镜头视距改为由转向时的视距平滑过渡到 1.5 万光年,不再中途贴近。结果:跃迁中 2.7–2.8 fps(SwiftShader 软件渲染,纯 2D 画布),截图 3–3.7 s;真 GPU 下隧道期 GPU 只剩 2D 合成。

## 3. 跃迁光效重做(效果图 ③)
- 2D 画布 2,400 根星光拉丝(手机 800 根,画布 0.8 倍分辨率;桌面 1 倍),按 8 个色桶合并成 8 次 stroke(每帧 8 次绘制调用,不是 2,400 次)。
- 颜色按半径:中心蓝白 → 浅蓝 → 操作台四色流光 青 #7fd6ff / 紫 #b48cff / 粉 #ff9fd0 / 琥珀 #f0c97a → 外缘红橙 / 红;中心白色光核 + 蓝白光环(前方压缩),外缘红移暗角(后方拉伸)。
- 星点按 1/z 投影:55% 从前方中心涌出(压缩、密),其余铺满视野;拖尾长度随半径增大(外缘拉成长线)。
- 包络:位置用 smootherstep(加速 → 巡航 → 减速),速度 v(u)=30u²(1−u)²/1.875 控制拉丝长度、线宽、亮度;遮挡度前 12% 淡入、后 14% 淡出,淡出时银河恢复渲染、镜头已到目的地。
- 减少动态 / 无 WebGL:不画拉丝,保持暗场淡入淡出(2.6 s),读数与进度条照常显示。
