# 天枢 Starhelm · v1.0-M1a 开发日志(2026-10-22)

## 一句话
1.0 HUD 上线:王磊定稿「A 舰桥为底 + B 对数尺度尺/常驻小航图 + C 大读数,守星人入底部控制台,任务抽屉默认展开」;地球旁换上真实 3D 月球,点它出此刻卡,可飞近环绕。

## 新增
- sh-hud.css / sh-hud.js(SHHUD):顶栏(← 创世计划 · 天枢 Starhelm · 星域面包屑 · 尺度条+光行时 · 小航图 · 画质 · 声音 · 全屏)、左侧任务抽屉(星域 I 五题 + 星域 II 四个实验室 + 2 个即将开放)、底部控制台(实时/北京时间 · 1×/1 天每秒/1 月每秒/倒放 · ±1 年时间轴带满月与日月食刻度 · 选日期 · 回到此刻 · 对数尺度尺 I–VII · 守星人提问与三级提示)、此刻卡(大读数 + 引线)。
- sh-domain.js(SHDOM):镜头距离 → 星域与尺度;?domain=2 直达月球;旧 HUD 中被替代的部分让位(信息面板、旧任务按钮/面板、读数条)。
- sh-focus.js(SHFOCUS):3D 月球(真实方向、真实大小比例、真实太阳照明、潮汐锁定正面朝地球;距离压缩到 4.2 地球半径);点击 → 此刻卡,自动转机位让地月同框;飞过去/回到地球;月相实验室入口。
- sh-time.js(SHTIME)、sh-now.js(SHNOW)、astronomy-engine 正式接入页面。
- SW:sh-v1.0.0-m1a。

## 自测
playwright + SwiftShader:1600×900、1024×768、390×844、减少动态、?domain=2、无 WebGL(HUD 不挂载,沿用 2D 版);零 page error。抽屉打开关卡与实验室正常。
