## 关键设计
- 向导只提问:提示分「方向 → 线索 → 半步示范」逐级打开,不直接给答案;提示用得多最少仍得 1 星。
- 任务 #3 规则可改:发射速度、高度(第 3 关取实时 ISS 高度)、引力 ×0.5/×1/×2;答案与实时 ISS 速度对照;星桥 → 宙律。
- 声音即规律:尺度之梯每跨一个数量级降调;大炮飞行音高随速度变化,入轨奏和声。BGM 仍默认关。
- 过境预报完全本机计算;无城市时提示先选城市,不触发定位。
- 导航/气象卫星只用内置快照,不增加 CelesTrak 请求;天宫/哈勃 2 小时本机缓存。
