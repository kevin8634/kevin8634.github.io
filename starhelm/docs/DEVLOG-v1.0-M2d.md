# 天枢 Starhelm · v1.0-M2d 开发日志(2026-10-23 凌晨)
## 一句话
星域 III 太阳系场景按 3D 画面规范升级:着色器太阳 + 粒子、4K 行星贴图、土星粒子环与本影、软圆点小行星带。
## 改动(全部在 sh-fx3d.js 的 SHFX3D.upgradeSolar,首次进入太阳系模式时自动执行)
- 太阳换成 SHFX3D.sun(米粒组织、黑子带、日冕射线、日珥、太阳风),旧光晕精灵隐藏,旧球体透明保留用于点选。
- 桌面端木星/土星/火星/水星/金星换 4K 贴图(hd/),手机仍用 2K 贴图包。
- 土星:真实环亮度贴图 + 按亮度分布的 2.6 万颗粒子环;环与粒子都接收土星本影。
- 小行星带/柯伊伯带改软圆点;太阳系星空亮度微调。
- 木星云带差速微动;伽利略四卫星(木卫一至四),方向由 astronomy-engine JupiterMoons 实时计算,距离对数压缩。
