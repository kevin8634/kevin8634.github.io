# 天枢 Starhelm · v1.0-M2a 开发日志(2026-10-22)

## 一句话
M1(航图 + 星域 I + 星域 II)封版;星域 III「行星世界」开放:现有太阳系模式并入 1.0 框架、跟随时间轴,点行星出此刻卡;新任务「火星上的一天有多长?」「今晚抬头能看到哪颗行星?」。

## 新模块
- sh-domain3.js(SHD3):SHTIME 接管 le-solar 的模拟时间(旧速度条在 HUD 下隐藏);点八大行星 → 1.0 此刻卡(离地球、光行时、离太阳、亮度星等、一天、一年、卫星数、下一次冲日/大距),按钮「飞近」+ 相关任务;岁星提问;?domain=3。
- sh-now.js:新增 SHNOW.planet / PLANETS(astronomy-engine 本机计算)。卫星数为 2025 年前后约数。
- sh-marsday.js:恒星日 vs 太阳日示意动画(地球/火星/金星,公转加快已标注)+ 真实一天一年表 + 火星协调时 MTC(Mars24 公式)与火星日编号;岁星 3 关,gn:sh:marsday。
- sh-tonight.js:按「我的位置」(无则北京)算今晚日落—日出间水金火木土的高度/方位/星等/最佳时刻;全天图 + 时间滑块;题目按今晚真实天空生成;gn:sh:tonight。

## 改动

- SW:sh-v1.0.0-m2a。
