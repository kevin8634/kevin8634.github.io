# 天枢 Starhelm · v1.0-M1c 开发日志(2026-10-22)

## 一句话

## 新模块
- sh-domain2.js(SHD2):星域 II 独立视图。太阳居中,地球位置(astronomy-engine HelioVector→黄道)、地轴倾角 23.44°、恒星时自转、月球方向(GeoMoon)与潮汐锁定都按真实时间;月球轨道按前后半个月真实采样;跟随 SHTIME 快进。大小距离为示意压缩(角注已标)。点太阳/地球/月球出守星人提问与入口(太阳活动、极光、日月食 / 飞近月亮、月相、潮汐锁定、潮汐)。打开时暂停母港地球渲染并隐藏旧界面。
- sh-atlas.js(SHATLAS):宇宙航图。七层光壳,点一层看「一问」、守星人、尺度、光走多久、任务点亮情况;已开放可前往;保留「航行星图」旧入口。
- sh-opening.js(SHOPEN):约 8 秒开场(七层光壳展开再收回地球),首访自动、可跳过(点击 / Esc),门户接力与深链不打扰;顶栏「↺ 开场」重播;减少动态为 2 秒静态标题;默认无声。
- sh-aurora.js:太阳风 → 磁层顶 → 沿磁力线落到两极(左),北极上空极光椭圆随 Kp 0–9 扩张(右,地磁纬度示意,注明与地理纬度差异);「此刻 Kp」读 NOAA SWPC(sh-eye.js);羲和 3 关,gn:sh:aurora。
