# 天枢 v1.0-M4w · 播报面板矮屏可读 + 离线角标 + 极光卡片失败态(2026-11-22)

接 66fd26a(M4v)之后,只改 /starhelm/;王磊已同意本小单,天枢窗口「测试通过就直接上线」。

## 改动
1. **568×320 横屏「地球重要播报」面板不可读**(sh-hud.css)
   - 原因:`.sh-cast` 的 `max-height: calc(100vh − --shh-acts − --shh-console − 120px)` 在 568×320 为 320−168−64−120 = −32px,
     被夹成 0,面板展开后整块不可见(只剩一条橙色边线)。
   - 主规则改为 `max(150px, 原公式)`:原公式 ≥150 的尺寸(1440×900 = 498、1000×760 = 358、375×667 = 269)取值与原来一致,外观不变。
   - 新增 `@media (max-height:500px)`:面板贴顶栏下方(`top: --shh-top + 14px`),在右侧与左侧按钮列并排;
     高 = 视口 − 顶栏 − 控制台 − 边距(下限 120px,568×320 时 174px,下沿在时间控制台上方);
     整块 `overflow-y:auto` 可滚动,展开时标题条吸顶,`z-index:39` 压过 3D 标签。收起态位置随之上移到同一处。
2. **实时总开关关时标题角标**(sh-cast.js + sh-hud.css):新增 `liveMark()`,随 `gdLine()` 调用——
   live=0 时角标「LIVE」改为「离线」(灰色)、红点熄灭不闪;live=1 不变。
3. **极光卡片失败时停在「加载中」**(sh-eye.js):
   - 原因:卡片在打开图层时渲染一次,之后 OVATION / Kp 的成功或失败只更新了底栏按钮,没回写卡片;Kp 失败还是静默 `catch(){}`。
   - 新增 `EYE.kpOk`、`auroraRows()` / `auroraTitle()` / `auroraRefresh()`:OVATION 或 Kp 每次完成(成功或失败)都检查——
     极光卡片仍开着(`#card.is-open` 且 kicker 为「极光预报 · NOAA SWPC」)就原地更新标题和数据行。
   - 「地磁活动」:有 Kp → 显示 Kp;任一失败或两者都结束仍无 Kp → 「暂不可用」;实时关 → 「实时数据已关闭…」(不变)。
     「预报时刻」:OVATION 失败 → 「暂不可用」(原为「—」)。
4. **CelesTrak / USGS(空间站、地震、星链)首屏加载**:保持不变(王磊同意)。
5. sw.js:`sh-v1.0.0-m4v` → `sh-v1.0.0-m4w`(sh-hud.css / sh-cast.js / sh-eye.js 均在预缓存清单)。
