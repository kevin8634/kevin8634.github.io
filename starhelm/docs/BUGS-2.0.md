## BUG-01 · 2026-10-29 18:20 · 星座里选的恒星到不了;远距恒星外观异常
截图(云盘):开发文档/BUG/BUG-01_星座恒星_2026-10-29.webp(线上 dd3e49b,1440 级桌面)

现象
1. 从导航目标栏「星座」页进入后,选星座里的恒星点,飞不到那颗星;最后锁定/抵达的是临时航点「HYG #2370」(K 型,537 光年,光度约 1,600 太阳,半径约 49 太阳),距离 1.377 AU、速度 0。
2. 这颗星画面不正常:几团白色光晕叠成「三叶草」形,恒星球体与另一个球错位成月牙。此时日心距离约 33,983,613 AU(约 539 光年)。

初判(未验证)
- 现象 1:星座页 go('con') 只把机头转向星座中心并打开插画(sh-x-catalog.js),插画上的星点不是可点目标;点到的是附近 HYG 点(SHXK 拾取),得到的是别的暗星。待核:插画锚点/连线星(SHX_CONSTART、SHX_CONSTART_HIP)与 HYG 拾取是否对得上,星座页是否该列出主要成员星并可锁定。
- 现象 2:离原点约 3.4×10^7 AU 时坐标精度不够(float32 / 相机相对坐标),恒星本体、日冕精灵各自抖开;或巨星半径(49 R☉)下光晕精灵尺寸/层数未按半径缩放。待核 sh-x-cockpit.js tempStar → body3d 的恒星层与远距浮动原点。

修复后测试:星座页选 3 颗不同距离的主星(近 <50 ly、中 ~500 ly、远 >1000 ly)各飞抵一次,1024 / 390 两档截图。
