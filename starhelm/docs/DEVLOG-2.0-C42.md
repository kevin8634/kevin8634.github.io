   - 手机打开卡片时用 camera.setViewOffset 把目标平滑上移 17% 屏高,不再被卡片挡住;竖屏区域视距自动拉远(≤1.6 倍)。

   - P1 / P2 粒子数减半,颜色按档位归一(系数 0.135 / sf,桌面约为原来的 1/7);核周弥散减亮约 1/3;M31 近距亮度下限 0.12 → 0.07(GAL 新字段 lo)。现在 P1 金黄、P2 偏蓝两团分得开,1024×700 与 390×844 都不过曝。

   - 本星系群(sh-x-lg.js)手机底栏同样改单行横滑,卡片贴到底栏上方。
3. M87 喷流按真实天球位置角对齐:PA = 290°(北起向东,Walker 等 2018),与视线夹角 17°(朝向我们)。
   - 新函数 skyB(ra,de):用 SHXTSG.scene 在天体位置差分出场景坐标中的「地球→天体」「天北」「天东」单位向量;m87Axes() 据此算喷流方向 JD 与 M87* 光环的南方向。

   - 光环南侧增亮改按真实天南方向。
   - 校验(tpa.py):相机放在银河(回望点)看 M87、up = 天北,喷流屏幕位置角 = 290.0°,与视线夹角 17.0°,天东投影在屏幕左侧(与真实天空一致)。
