## 新增
- **sh-stars-data.js**(60 KB,不需分片):HYG 恒星库 v4.1 派生,4 268 颗(100 光年内 4 062 颗含太阳 + 100–3000 光年视星等 ≤3.5 的亮星 206 颗;TRAPPIST-1、蒂加登星按 NASA 系外行星档案补入)。每星 5×int16 base64(位置 0.1 光年、绝对星等、B−V);另含 45 颗标注星序号、北斗七星空间速度、171 个系外行星宿主。构建脚本 docs/build/build_stars.py。许可 CC BY-SA 4.0(文件头已注明)。
- **sh-domain5.js(SHD5)**:星域 V 独立视图(同 SHD2 做法:自带渲染器,打开时暂停母港地球渲染)。
  - GPU 粒子恒星场:颜色 = 温度(B−V → Ballesteros 温度 → 黑体色),大小/亮度 = 着色器里按「绝对星等 + 镜头到星的真实距离」算出的视星等,所以站在太阳旁就是真实夜空,飞远后星座自然变形。
  - 背景 SHFX3D.skyMesh(已对照北斗校准恒星坐标与星空贴图同向);25/50/100 光年刻度环;太阳金环;系外行星宿主青色光环;北斗连线。
  - 顶部四个视角:☉ 站在太阳旁看星空 / ⤢ 100 光年全景 / ✦ 北斗七星 / ◎ 系外行星(TRAPPIST-1)。
  - 点星 → 1.0 此刻卡(SHHUD.showNow + 包装 SHNOW.card,id = `s5:<序号>`,badge「星表数据」):离地球、光行时、「你看到的是 X 年前的它」、星光出发年份、颜色·温度、亮度(太阳倍数)、类型、行星数、趣闻;同时一镜到底推近到三层着色器恒星特写(按温度换色,大小示意)。按钮「◎ 推近 / 环绕」「⤢ 回到全景」。
  - 标签:近邻恒星(比邻星、南门二、巴纳德星、天狼星、天苑四、天仓五、牛郎星、织女星、北落师门、大角星……)、远方亮星(北极星、参宿四/七、天津四、心宿二、角宿一、老人星,只在太阳附近显示)、北斗七星(天枢金色「本世界同名星」)、系外行星系统;按优先级避让,手机最多 9 个。
  - 守星人「织女」底部台词;面包屑 星域 V › 100 光年恒星场 / 太阳旁的星空 / 北斗七星 / <星名>;尺度尺。
  - 无 WebGL(仅本视图渲染器创建失败时)→ 2D 画布星图退回,点星/此刻卡照常。减少动态:不自动旋转,镜头飞行 0.4 秒。
- **sh-d5-tasks.js**:四个任务(3 关、每关最少 1 星、提示三级、存 gn:sh:<id>、深链 ?task=<id>,本文件自己处理深链,不改 sh-link.js):
  - sh.starlight「你看到的星光有多老?」停靠面板:比邻星光行 4.2 年 / 织女星光哪年出发(随今年计算)/ 北极星光出发时的朝代(明万历)。
  - sh.exoearth「宇宙里还有别的地球吗?」全屏实验室:凌星 + 解析光变曲线;可改行星大小(0.5–12 个地球)、换恒星(太阳 / TRAPPIST-1);第 2 关为「改规则」目标关(调到木星大小);「在星图里找它」飞到 TRAPPIST-1。
  - sh.sundie「太阳会死吗?」全屏实验室:100 光年真实恒星赫罗图 + 太阳一生(年龄滑块 0–138 亿年,主序/亚巨星/红巨星/氦燃烧/渐近巨星/行星状星云/白矮星);第 2 关目标关(拖到红巨星顶点)。
  - sh.constel「星座为什么会变形?」停靠面板:飞船离开太阳 0–100 光年侧飞(目标关 ≥60 光年)、时间 ±10 万年(只移动北斗七星,HYG 空间速度)。
