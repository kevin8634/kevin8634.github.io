## 四、玩法流程
1. 主界面新增「🚀 航行」按钮(M1 航图里也有「登舰航行」)。
2. 进入驾驶舱,星璃打招呼 → 打开航图选目的地(对数尺度 8 圈)。
3. 选引擎:合适的引擎带 ✓;星璃先让你猜「要飞多久」(三选一)。
4. 太慢(船上与地球都超过 100 年)时星璃提醒,可换引擎或用演示模式出发;猜想类引擎出发前会声明「基于尚未证实的理论」。
5. 操纵:长按点火 / 拨动参数 / 时机按键 / 转盘对准,四种方式对应不同引擎。
6. 穿梭:仪表实时显示距离、速度、地球时间、船上时间、信号回地球时间、演示快进倍数;近光速航行展示时间膨胀。
7. 抵达:星域标题卡;已测绘星域由该星域向导接手,未测绘星域只能远观。

## 七、声音接入(2026-10-19 晚,按总指挥《声音设计指南 v1.0》)
- 源码 `audio/synth.py`(numpy+scipy 纯程序合成,种子 7,可重现)+ `audio/encode.sh`(ffmpeg → AAC)。WAV 原件归档在 `genesis_brief/本世界资料/音频源/wav/`,不上线。
- 调式 **D 利底亚**(与门户同调),音色 **钟声 + 深空垫**。背景音乐「天枢 · 深空巡航」96 秒无缝循环,和弦 D(add#11) → E/D → Bm6 → A;192k,2.3 MB;响度 -18.5 LUFS,接缝差 0.006。
- 音效 25 个(128k,每个 ≤66 KB):

| 音效 | 用在哪里 | 声音即规律 |
|---|---|---|
| click / toggle-on / toggle-off | 按钮、图层开关 | 开=上行五度,关=下行 |
| select / lock | 选中、锁定目标 | — |
| whoosh | 镜头飞行、航行穿梭 | 飞得越久播放越慢、越低沉 |
| boom / open / close | 切换地球/太阳系、进出航行、开关航图 | — |
| unlock / soft | 任务过关 / 「再想想」 | — |
| sector-1…8 | 航图点选、抵达星域 | 越远音越高;猜想外圈带拍频,悬而未决 |
| ignite-1/2/3 | 引擎点火 | 实测低沉轰鸣 / 推断明亮上扬 / 猜想飘忽闪烁 |
| arrive / blip / tick | 抵达、星璃说话字音、操纵提示 | — |
| (实时)嗡鸣 | 太阳系时间加速、星际航行 | 音高与亮度随速度的对数升高 |
| (实时)glass / hum | 尺度之梯、牛顿大炮 | 越远越低 / 炮弹越快越高(M1 已有) |

- 接入:声音默认关;偏好键 `gn:sh:_pref`({music,sfx},下划线开头不影响门户点亮);只在用户手势后创建 AudioContext 并下载音频,默认关闭时一个音频文件都不下载;切后台淡出并挂起;同一音效 80ms 节流;本世界无悬停音效;`LE.audio.duck()` 预留给视频。SW 升到 `sh-v0.3.1`,m4a 首次使用时缓存。
- 测试:默认 0 个音频请求;打开音效加载 25 个;打开音乐才加载音乐;航行全流程无报错。
