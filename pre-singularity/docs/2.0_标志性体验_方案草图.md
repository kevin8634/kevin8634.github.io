# 奇点前夜 2.0 · 标志性体验方案草图(待王磊选定,未开发)

**名称(暂定):「玻璃心智」Glass Mind** —— 一问:「一个比你聪明的心智,你怎么知道它在想什么?」

**画面**:夜色顶层公寓(沿用 1.0 黎明天色)中央,一颗等身高的**玻璃神经核**:r186 MeshPhysicalMaterial 透射+色散+薄膜虹彩,内部 30 颗知识神经元为发光体;ACES/AgX 色调、景深、体积光束、窗外城市逆光,电影写实。萤是核内流动的光。

**改规则(七律②)**:学习者手里三枚「玻璃滑块」——目标(它要什么)/ 能力(多聪明)/ 透明度(能看见多少内部)。拖动后玻璃实时变化:透明度低→玻璃起雾、只见外壳;能力高→核内光路分叉、速度超出人眼;目标偏一点→光路在玻璃深处悄悄绕路(对齐问题可视化)。一屏内只留滑块与一句向导提问。

**三幕(每幕 ≤1 屏文字,七律⑤)**:①看得见:调透明度,找到被遮挡的那条光路(接 v0.9.4「巨人的目光」遮挡归因)。②看不见:能力调高后用「探针」打光,只能照亮一小片——体会可解释性的极限。③说好的:设定目标与约束,看它在 3 个城市情境里怎么走;没有标准答案,向导只提问(七律④)。

**声音(七律⑥)**:玻璃共鸣音由光路数与能力值驱动,透明度越低声音越闷;默认关。

**一张总图 / 星桥(七律③)**:玻璃核即本世界 3D 知识图谱,终章 ps.gate 的「门」从核中打开。

**零打扰(七律⑦)**:纯本地、无注册;不计分不排名;生成式 AI 默认关。

**性能**:高=透射+色散+辉光;中=无色散、透射降采样;低/无 WebGL/减少动态=1.0 Canvas 版,功能不减。手机像素比 ≤1.5。

**备选**:B「镜厅」(无数玻璃镜面映出 AI 的多个自我,讲自我改进);C「冰封瞬间」(时间冻结的玻璃城市,讲智能爆炸的速度)。推荐 A。
