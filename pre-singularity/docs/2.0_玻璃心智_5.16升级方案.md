## ③ 方案
**A「玻璃脑剖面」(推荐)**:原路由 glass/ 原地升级,玩法/三幕/进度键 gn:ps:glass/1.0 任务 id 全不变。
- 核心体验:琥珀-冰蓝双色玻璃脑(融球分叶)悬在暗室,核内粗光路流动;玻璃前悬「它说的理由」文字牌,玻璃后是「真实光路」,高档真折射把两者叠在一起——"看得见的话"和"看不见的路"同框。幕一透镜探针照亮;幕二隐藏念头在核内蠕动、透明度滑块让玻璃由毛变清;幕三 Compare 分界线对照;终章半脑分开+门内星海。

- 档位:high=缓冲折射+色散+选择性 Bloom;mid=物理透射、无色散;low/减少动态=现有 Canvas 2D 平面回退。
- 风险:双重渲染掉帧(手机降缓冲分辨率+样本数);融球每帧重建贵(只在滑块变化时重建);SwiftShader 观感仍不代表真机。
