# /shared/3/ · LICENSES

v0.1 全部代码为创世计划自写,无第三方源码、无外部依赖。

- mulberry32、sfc32:公开发表的伪随机数算法(Tommy Ettinger / Chris Doty-Humphrey),按公开描述自写实现。
- RK4、速度 Verlet:经典数值积分方法,教科书公开方法。
- 画质分档规则与门户 portal3/p3tier.js 一致(本项目自有)。

后续 v0.2 组件只借鉴 React Bits、Aceternity UI、ThreeUI、MotionSites 四站的免费公开演示思路,原生改写,届时在此逐条署名。
