## 推导要点与数值(脚本复算:总指挥工作区 work/d110/nums.py)
- **ma.l1.amgm**:(√a−√b)²≥0 → (a+b)/2≥√(ab),a=b 取等;x+y=L/2 → xy≤L²/16;L=40:S_max=100 m²(12×8=96);积定和最小 2(x+y)≥4√S;「一正二定三相等」。检查题 L=24 → 36 m²。
- **nv.l1.pendulum**:切向回复力 −mg sinθ → 小角度 sinθ≈θ、x=Lθ → F≈−(mg/L)x → a=−(g/L)x 对照 a=−ω²x → T=2π√(L/g);L=1 m、g=9.8:2.0071 s;秒摆 0.9929 m;10° 时 sinθ 相对误差 0.51%;精确大摆角周期比(AGM)10°:1.0019、30°:1.0174、60°:1.0732;g=4π²L/T²。检查题月球 √(9.8/1.62)≈2.46 倍。
- **ef.l1.ph**:Kw=1.0×10⁻¹⁴(25 ℃);pH=−lg c(H⁺);电荷守恒 c(H⁺)=c+Kw/c(H⁺) → x=(c+√(c²+4Kw))/2;c=10⁻⁵:5.0000、10⁻⁶:5.9957、10⁻⁷:6.7910、10⁻⁸:6.9783(H⁺ 约 90% 来自水)、10⁻⁹:6.9978。检查题 10⁻³ 稀释 100 倍 → 5。卡内安全提示「酸入水」。
- **ls.l1.hardyweinberg**:p+q=1;随机交配 p²、2pq、q²;下一代 p'=p²+pq=p;q²=1/10000(示例数)→ q=0.01 → 2pq=0.0198、为患者的 198 倍;五个前提。检查题 q²=0.16 → 2pq=0.48。卡内免责:真实白化病多基因、发病率因人群而异(MedlinePlus:欧洲约 1/12000–1/15000、非洲约 1/4000–1/7000)。
- **sh.l1.parallax**:tan p=1 AU/d → 小角 d≈1 AU/p(rad)(弧长公式)→ 1 pc=648000/π AU=206264.806 AU=3.26156 ly → d(pc)=1/p(″);比邻星 Gaia DR3 768.0665±0.0499 mas → 1.30197 pc=4.2465 ly;p∝1/d,1838 年首测恒星视差。检查题 0.1″ → 10 pc。
- **ps.l1.leastsquares**:教学虚构数据 (1,2.1)(2,3.9)(3,6.2)(4,7.8)(5,10.0);Q(w)=55w²−219.4w+218.9;w*=Sxy/Sxx=109.7/55=1.994545,Q_min=0.0984;w←w−ηQ'(w) → e_{k+1}=(1−110η)e_k;收敛 0<η<1/55;η=0.005 十步 1.993866;η=0.01 公比 −0.1;η=0.02 公比 −1.2 发散;η=1/110 一步到位(「想一想」只问不答)。
- **lt.l1.bayes**:P(D)=0.001、P(+|D)=0.99、P(+|D̄)=0.01;P(+)=0.01098;P(D|+)=0.0902;自然频率 99/(99+999);独立复测 → 0.9075。检查题(1%,90%,10%)→ 8.3%。卡内免责「教学示例,不构成医疗建议」。
