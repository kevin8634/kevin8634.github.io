- **教学误差 0.8 ppm**:NOAA 月均值的不确定度通常只有 0.1–0.3 ppm,但平滑的「趋势 + 季节」模型抓不住厄尔尼诺等年际起伏(0.5–1 ppm 量级);取统一 0.8 ppm 让χ²、BIC 与过关线有意义。**这个取值参考了最优模型的残差,是事后设定**,所以最优组合χ²_ν≈1.04 不能当作模型「正确」的证据;过关线也依赖它。

## 积木与公式(x = 小数年份 t,y = CO₂ ppm,参考年 2000;线性纵轴 305–450)
- 合成 `combine:"sum"`。
- **线性趋势** `co2lin`:a + b(t−2000)。a 300–420 ppm,b −1–5 ppm/年。
- **二次加速** `co2quad`:c(t−2000)²,c −0.05–0.08 ppm/年²(增长率每年再增 2c)。
- **基线 + 指数** `co2exp`:280 + A·e^{(t−2000)/τ}(工业前基线 280 ppm 固定),A 20–200 ppm,τ 10–200 年(对数滑杆)。与「线性 + 二次」是竞争的两种趋势。
- **季节 · 年周期** `harm1`(修饰积木):A₁cos 2π[t − (m₁−½)/12],A₁ −6–6 ppm,m₁ 0.5–12.5(峰值月份,1 = 1 月中)。
- **半年谐波** `harm2`(可选修饰):A₂cos 4π[t − (m₂−½)/12],A₂ −3–3,m₂ 0.5–6.5。振幅允许为负(等于峰移半个周期),以免 LM 卡在振幅 = 0 的边界(开发中遇到:A₂ 下限为 0 时从 m₂ = 3.5 出发会卡死在 0)。
- 派生量(协方差一阶传播,χ²_ν>1 时放大):**2026-09 年增长率** = 趋势积木之和在 t = 2026.7083 的斜率(中心差分);**季节峰谷差** = 年周期 + 半年谐波一年内 max − min。
- 统计与评分沿用引擎:χ²_ν = χ²/(N−k)、BIC = χ² + k·lnN(N = 823)、亮度分。过关:χ²_ν < 2 且炉中含「季节 · 年周期」→ 点亮「CO₂ 炉徽章」。
