## 积木与公式(x = t 天,y = C 累计确诊,对数纵轴 100–100 万)
- 合成 `combine:"sum"`:C(t) = Σ 分量;「封城干预」是修饰积木,只改 SIR 的 β。
- **指数增长** `expo`:C = C₀·e^{rt};C₀ 10–5000 人(对数滑杆,初值 100),r 0.01–0.6 /天(初值 0.15)。派生量:翻倍时间 ln2/r。
- **逻辑斯谛** `logis`:C = K/[1 + (K/C₀ − 1)e^{−rt}];K 1–1000 万人(对数),r,C₀。
- **SIR** `sir`:dS/dt = −βSI/N,dI/dt = βSI/N − γI,C = N − S(= I + R,累计感染);S(0) = N − I₀,I(0) = I₀,R(0) = 0。RK4,步长 0.05 天,整条轨迹按参数缓存。参数 β 0.02–1.5 /天;**γ 默认锁定 1/7 /天**(约 7 天,与 1.7 航线同一假设,锁定参数不计入 k,可解锁);N 1–10000 万人(对数,有效人群);I₀ 10–3000 人。派生量 **R₀ = β/γ**。
- **封城干预** `lock`(kind `mod`,牛顿修正类引导积木):β(t) = β·[1 − q/(1 + e^{−(t − t_L)/1 天})];q 0–0.95,t_L 0–60 天(初值 14 = 2020-03-09 全国封城宣布日)。不在炉里时 q 取 0(`off`),只有它没有 SIR 时模型为 0。派生量:干预后 β(1−q)/γ。
- 派生量不确定度:自动拟合返回协方差(原始参数空间,χ²_ν>1 时乘 χ²_ν),派生量按一阶误差传播;**锁定参数(如 γ)不计误差**,界面写明。
- 统计与评分沿用引擎:χ²、χ²_ν = χ²/(N−k)、AIC = χ²+2k、BIC = χ²+k·lnN(N = 128),亮度分 S = 100·exp(−max(0,(BIC−N)/N)/1.5)。
- 过关:χ²_ν < 2 且炉中同时含「SIR」与「封城干预」→ 点亮「疫情炉徽章」。

## 审校要点(审校不挡上线;勘误跟进修)
**数学 01 星图**
1. SIR 数值解:RK4 步长 0.05 天、线性插值;终末规模与 z = 1 − e^{−R₀z} 对照(R₀ = 2.5 时 0.8926,误差 < 2×10⁻³);早期与 I₀[1 + β/(β−γ)(e^{(β−γ)t} − 1)] 对照。
2. 统计口径:5% 相对教学误差(非独立、非高斯的累计数据用χ²是教学近似);BIC 只比同一数据、同一误差下的模型;派生量σ为一阶传播且不含锁定参数。
3. 干预台阶用宽 1 天的 logistic 平滑(为了数值导数可用),t_L 是「确诊曲线上看到的生效日」。
4. 胶囊截断拟合从当前参数出发的局部最优(LM),不同起点可能给出不同预测——是否需要在文案里点明。

**生物 04 生命源码**
1. 「确诊」≠「感染」:累计确诊受检测量与检测政策影响,N≈35 万是确诊口径的有效人群,不是真实感染规模或易感人数。
