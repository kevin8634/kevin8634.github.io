## 主要差距(如实)
1. **银河带质感**:01c 的银河是 AI 合成的“理想化”银河(粉紫星云点缀、核心橙黄更饱和、带更规整);真实 ESO 全景尘埃更灰、更碎,且纵向拉伸 ~1.6 倍后星点略呈竖椭圆。可选改进:换更高分辨率的银心区域影像(如 ESO 银心 GigaGalaxy 第二幅)或做色彩分级 LUT。
2. **海面**:01c 海面有明显的大涌浪明暗起伏与柔和的彩色倒影光斑;实时版倒影更“碎”(高频闪烁)、波浪明暗层次不足、远处缺薄雾。V6 计划加屏幕空间涌浪阴影 + 倒影模糊。
3. **星云带**:01c 是一条连续、融合的彩色星云;实时版是 7 张影像羽化拼接,块状感仍在(尤其左侧创生之柱与右侧船底座翻转件),色彩比 01c 更饱和、对比更强。
4. **光柱**:01c 光柱更宽更柔、底部融入星云;实时版核心偏窄、底端淡出较早。
5. **黑洞**:01c 为有体积感的暗球+微弱边光;实时版是平面暗盘+光子环,环略显“图标化”。
6. **水下背景**:01c 水下顶部有青灰色水体感与更密的细碎星点;实时版更黑、星点更少更大。
7. **手机 375×812**:采用“取 01c 中部”的覆盖构图(约 4 道光柱可见),银河被放大显得更粗;与 01c 横幅不可完全等价。
8. 截图由软件渲染(SwiftShader)生成,真机 GPU 下 Bloom/颗粒观感会略有差异;动画(星闪、海浪、光柱流动、星系自转、水线波动)截图无法体现。

## 水体物理(r6,deep/opening.js)

| 项 | 公式 | 参数 | 落点 |
|---|---|---|---|
| 折射 | 斯涅尔 sinθi = n·sinθt | n = 1.33;θi = 星位横向偏移 × 0.42 rad(画面两侧更斜) | 光柱在水中按 tanθt 斜出,入水处折角 = θi − θt(pillarMat uSk) |
| 斯涅尔窗 | θc = asin(1/n) ≈ 48.6°,全视锥 ≈ 97°;窗内 sinθa = n·sinθw | 天顶在屏幕上方 y=1.06,角尺度 1.9 rad/屏高 | 水下仰视(水线越过屏顶后、进入深空前,`?still&z=-70`):窗内为压缩的水上天空(地平线挤成亮环),窗外为全内反射的暗面(镜像水下场景 ×0.35) |
| 窗内透射 | T = 1 − [F0 + (1−F0)(1−cosθa)^5] | F0 = 0.0201 | 越靠窗边越暗 |
| 吸收 | Beer–Lambert I(z) = I0·e^(−K·z),按通道 | K = (0.38, 0.07, 0.035) /m(R/G/B ≈ 650/550/450 nm,清澈海水量级) | 光柱沿长度 0→5 m;整体画面按像素水深 z = 6·(水线下屏高比) + 24·(下潜量) m;红/橙柱的红通道衰减最快 → 光柱与色调随深度向蓝青偏移 |
| 艺术平衡 | 整体吸收只施加 60%,其中 35% 取中性灰 | — | 深处星系/星云仍可辨 |
| 离开水体(设定) | 水体占比 wa = 1 − smoothstep(0.15, 0.75, 深空混合) | — | 进入深空层后吸收、内散射、底色逐步撤去,恢复真空色彩:下潜穿过的是「星海」的水层,穿透后即真空 |
| 内散射 | + 水色 WC·(1 − T_G)·0.018 | WC = (0.05, 0.42, 0.55) | 深处青蓝底 |
| 前向散射 | 光柱半宽 w = 0.2 → 0.42(随深度 y^0.8),核心宽 0.8w | — | 光柱随深度变宽变柔;核心较 V1 加宽 |
| 丁达尔微粒 | 屏幕 3px 网格 0.12% 亮点,亮度 ∝ 所在处光柱亮度 | — | 只在光里看得见 |
| 焦散 | 迭代扭曲正弦网格,强度 ∝ e^(−z/1.2 m) | — | 水面下几米内的光纹 |
| 水面菲涅尔 | Schlick R = F0 + (1−F0)(1−cosθ)^5,颜色 = 水体·(1−R) + 反射·R | F0 = ((n−1)/(n+1))² = 0.0201 | 掠射角反射强、俯视透射多 |

## V1.3 黑洞:史瓦西测地线光线追踪(2026-10-30,总指挥)
- 原 V1.2 为二维解析近似(暗盘+细环+半边透镜弧),近侧盘只亮一侧、下方次级像缺失。
- 改为逐像素反向追踪光子:rs=1,加速度 a=−1.5·h²·p/r⁵(等价 Binet 方程 u''+u=1.5u²),速度 Verlet,步长 0.06r(桌面 220 步 / 手机 120 步)。
- 薄吸积盘 r∈[3,13]rs(内缘=ISCO),温度 T∝r^−¾(1−√(r_in/r))^¼,峰值 4600 K;开普勒速度 β=√(M/(r−2M));多普勒 δ=1/(γ(1−β·n))×引力红移 √(1−rs/r),强度 ∝ g⁴、色温 ∝ g;黑体色 Tanner Helland 近似。
- 盘可多次穿越:自然得到远侧盘经透镜绕到阴影上方的「帽子」与下方次级像、光子环;观者仰角约 6°。左侧朝向观者故更亮更白。
- 预乘 alpha 合成:被视界捕获=不透明黑影,逃逸光线透明露出后方真实影像。手机黑洞内移至可视区。
- 自测:桌面 1440×900、手机 390×844、?three=169、z=-40:0 页面错误、0 本站 404。
