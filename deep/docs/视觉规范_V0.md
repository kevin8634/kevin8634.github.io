## 4. 后期参数
| 项 | 值 |
|---|---|
| 色调映射 | ACES Filmic(OutputPass),曝光 1.0 |
| Bloom | UnrealBloomPass:水面 threshold 0.85 / strength 0.5 / radius 0.4;入深空后线性过渡到 0.2 / 0.6 / 0.55 |
| 胶片颗粒 | 0.035(随亮度开方加权),每帧变化 |
| 暗角 | 0.85,椭圆(宽高比上限 1.8) |
| 天空 | 曝光 1.05,饱和 1.65,暖色偏 (1.08,0.98,0.90),银河核心额外提亮 0.5 |
| 海面 | 9 组方向波法线(随距离衰减),Schlick 菲涅尔 F0=0.02,天空反射 ×0.45,七星闪烁三档 pow 6000/900/150 |
| 水线 | 三频正弦波动;线上 2px 高光 0.22、下方 7px 暗带 |
| 降档 | 手机(宽<600):像素比 ≤1.25、无 MSAA、星点 1400/2600(桌面 3200/7000);低帧(>42ms 连续 72 帧)先关 Bloom 再降像素比 |
| 减少动态 | prefers-reduced-motion:只渲染一帧 F0 静态图 + 分层卡片列表 |
