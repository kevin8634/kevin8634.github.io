# 深空 2.8「模型炼炉 · 分龄版」(炼炉 F5,2026-11-12,总指挥)

一句话:四个炼炉(暗物质 / 开普勒 / 疫情 / CO₂)各有三档——**星辰层 l1 滑杆版**(高中)、**星系层 l2 原版**(大学,行为与存储不变)、**星穹层 l4 开放问题版**(研究者)。全部由各炉 JSON 的 `tiers` 数据驱动,引擎 `applyTier` 生成该档配置。

## 入口
- 深空层里「⚗ 模型炼炉」按钮现在在星辰、星系、星穹三层都显示,档位跟当前层走:星辰 → l1,星穹 → l4,其余(星系、水面、星河、减少动态分层卡)→ l2 原版。
- 炼炉页眉新增「档位」下拉(星辰 · 滑杆版 / 星系 · 原版 / 星穹 · 开放问题),切炉时沿用当前档位;l1 拟合仪里有「我想看完整版 ▸」一键切到 l2。
- 深链:`/deep/?forge=<dm|kepler|epi|co2>&tier=<l1|l2|l4>`;不带 tier 时与 2.7 完全一致(飞到星系层、开原版)。带 tier 时先飞到对应层(l1→星辰、l4→星穹)。

## tiers 配置字段
- `l1`:`blocks` 预置在炉里的 1–2 块;`tray` 架上可加的积木(其余积木不出现);`knobs` 露出来的旋钮(每块 ≤2 个);`p` 隐藏参数的固定值(取星系层最优拟合附近);`text` 积木文案覆盖(tex/note);`pass`(`fitMin` 贴合度门槛);`guide`(更浅,只提问);`intro`、`subtitle`。
- `l4`:`extraBlocks` 星穹专属积木;所有参数默认解锁(可手动锁);`stats` 统计口径;`open` 2–3 个开放问题 `{t, q, try, src:[{t,url}], checked}`;可选 `derived` 覆盖派生量名。
- 贴合度 = 每颗星按光丝颜色计分(绿 |z|<1 计 1、黄 1–3 计 ½、红 >3 计 0)的平均 ×100。

## 审校要点(06 觉弈 · 体验与难度;写入文档,不派发)
1. 星辰层难度:每炉只露 1–3 个滑杆(每块 ≤2),隐藏参数固定在星系层最优附近,所以滑杆「拖得到」过关;请判断是否过于容易(尤其开普勒只需拖 n),是否该把门槛从 75–80% 调高,或在开普勒去掉 C 固定改露两个旋钮。
2. 贴合度的定义(绿 1、黄 ½、红 0)是否直观;红光丝占多数时贴合度很低(暗物质只用恒星盘约 13%)——对高中生是否打击过重,是否需要在引导里先肯定「内圈已经贴住了」。
3. 引导只提问不给答案:请逐条看 l1 引导有无「暗示过强」(如暗物质 sub「架子上还有一块积木」、疫情 sub 提到 3 月 9 日封城)。
4. 疫情 l1 直接给 SIR + 封城而不是指数 → 逻辑斯谛:高中更熟悉逻辑斯谛模型,但它在本数据上贴合度只有约 29%;请定夺星辰层要不要换成「指数 vs 逻辑斯谛」的路线。
5. 星穹层开放问题的措辞是否中立(MOND/ΛCDM、封城归因都有争议);是否需要补「反方」一手来源(如对 Flaxman 2020 的商榷)。
6. 星穹层所有参数默认解锁,疫情 γ 解锁后 R₀ 掉到约 1.45 且与 β 几乎完全相关——这正是开放问题 1 要展示的,但请确认不会让研究者误以为「R₀ 就是 1.45」(派生量名已改为「γ 若解锁则由数据拟合;± 仅统计误差」)。
7. 手机竖屏页眉两个下拉并排(炉 + 档位),请看 375 宽度是否拥挤。
