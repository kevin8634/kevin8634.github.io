## 引擎与界面增补(暗物质炉行为不变,forge_dm_check.mjs 仍全过)
- `axes.x.log` / `axes.y.log`:对数轴,每十倍画 1、2、5 网格,像素够宽才标 2、5;曲线在对数空间均匀取样。
- `axes.{x,y}.sym / unit / short / dp`:提示框、胶囊文字、手机纵轴短标签用;缺省回到 r/kpc、v/km/s(暗物质炉原样)。
- `data.label`(点名列)+ `data.showLabels`:图上标行星名;窄图(<640 px)去掉括注(「地球(地月质心)」→「地球」);与胶囊标签或右边界相撞时改标在星点左上。
- 积木 `kind:"factor"`:乘在合成结果上的修正因子,数据点 i 处读列 `col`,因子 = (1 + β·μ)^pow(pow 默认 −1/2);非数据点 μ 取 0;不画分量曲线;炉里只有因子没有主项时模型为 0。
- `pass.params:{k:[lo,hi]}`:过关还要求参数落在区间。
- 参数 `dp`:旋钮读数小数位;拟合结果有效位上限 4 → 6(σ 到 10⁻⁵ 量级时不再显示 ±0.0000)。
- 胶囊:`dp` 小数位;`truth.label` 给 value 型真值的出处说明(原来固定写「n 个观测点加权平均」)。
- **标签避让(修 375×667)**:先排胶囊标签(及已封存胶囊的圆圈、「数据外」),分量曲线标签与之相交时先试放到曲线下方,不行再逐级下移;封存圆圈压住「胶囊」字时,字挪到圆圈下方;「数据外」被胶囊压住时挪到图底。375×667 暗物质炉「暗物质晕」不再与「胶囊」/封存圆圈重叠。

## 开普勒炉设计
- 数据:JPL SSD「Approximate Positions of the Planets」Table 1(1800–2050 AD)。a = a₀(au);T = 36000/L̇(L̇ 平黄经变率,deg/儒略世纪 → 恒星周期,儒略年);地球行为地月质心。μ = m/M☉(NSSDCA 质量,太阳 1.9884×10³⁰ kg)。
- **误差**:源数据不给误差。L̇ 的统计精度约 10⁻⁵,但这些根数是 250 年最佳拟合值而非二体轨道,T/a^1.5 偏离二体关系最大约 6×10⁻⁴(海王星)。本站取**教学相对误差 σT/T = 2×10⁻⁴**(数据 note、炉 sources、LICENSES 均写明,非测量误差)。
- 坐标:x = a(au)0.2–60,y = T(年)0.1–400,双对数;合成 `combine:"sum"`。
- 积木:
  - 幂律 `T = C·aⁿ`(C 0.1–10 对数滑杆,初值 1;n 0.5–3,初值 1 —— 初始金线故意是正比);
  - 正比 `T = k·a`(错误对照,k 0.001–20 对数滑杆);
  - 牛顿修正 `f = (1 + β·m/M☉)^(−1/2)`(β 默认锁定 = 1,不计入 k;可解锁让数据「称」行星质量)。
- 过关:χ²_ν < 2 且炉中含「幂律」且 n ∈ [1.45, 1.55] → 点亮「开普勒炉徽章」。
- 引导(只提问):空炉 →「这个『越』是怎样的关系?」;只有正比 →「能同时穿过水星和海王星吗?内外行星光丝各偏哪边?斜率一样吗?」;只有牛顿修正 →「周期本身由谁给出?」;幂律未过关 →「C 和 n 各管金线的什么?」;幂律+牛顿过关 →「χ² 变小还是变大?真实效应为什么看不出来?」;过关 →「n 最接近哪个简单分数?写成 T 的几次方与 a 的几次方成正比;C 为什么几乎正好等于 1?」。
- 胶囊(均为演示,unlockAt = null,开封立即对比):
  - 谷神星 a = 2.765553 au,真值 T = 1679.853120 天 = 4.599187 年(JPL SBDB 1 Ceres,轨道解 48);
  - 冥王星 a = 39.588629 au(数据外,检验外推),真值 T = 90981.716 天 = 249.0944 年(JPL SBDB 134340 Pluto,历元 JD 2457588.5 = 2016-07-31);界面注明与海王星 3:2 共振、长期平均周期略有差别。
  - 真值误差同取 2×10⁻⁴ 相对(谷神星 ±0.00092 年,冥王星 ±0.05 年)。

## 复算结果(node deep/docs/forge_kepler_check.mjs;与 scipy least_squares 独立复算一致)
| 炉中积木 | k | χ² | χ²_ν | AIC | BIC | 亮度分 | 参数(±σ) | 过关 |
|---|---|---|---|---|---|---|---|---|
| 正比 | 1 | 6.10×10⁷ | 8.71×10⁶ | 6.10×10⁷ | 6.10×10⁷ | 0 | k = 0.956 ± 0.240(8 颗全红) | 否 |
| **幂律** | 2 | **3.08** | **0.513** | 7.08 | **7.24** | 100 | **C = 0.99997 ± 0.00009 年,n = 1.49986 ± 0.00005** | 是 |
| 幂律 + 牛顿修正(β=1 锁定) | 2 | 5.39 | 0.899 | 9.39 | 9.55 | 88 | C = 1.00002 ± 0.00009,n = 1.49988 ± 0.00005 | 是 |
| 正比 + 幂律 | 3 | 8.72 | 1.745 | 14.72 | 14.96 | 56 | k 推到下限 0.001,C = 0.9989,n = 1.5002 | 是(但 BIC 多 7.7) |
- 2n = 2.99971 ≈ 3,即 T² ∝ a³;ΔBIC(正比 → 幂律)≈ −6.1×10⁷。
- 幂律最优解逐星残差(σ):水 −0.45、金 −0.03、地 +0.22、火 +0.45、木 −0.81、土 +1.30、天 −0.20、海 −0.49(7 绿 1 黄)。
- 牛顿修正让木星、土星的残差改善方向正确,但天王星、海王星(根数拟合中的摄动残留约 −5×10⁻⁴)更大,总 χ² 反而 3.08 → 5.39:**真实存在的效应小于这份数据的系统误差**,这是引导要学习者自己发现的点。解锁 β 拟合:β = 0.24 ± 0.48(与 0 和 1 都相容,数据称不出行星质量)。
- 胶囊(幂律最优):谷神星预测 4.5983 年,真值 4.5992 ± 0.0009 → −1.0σ 命中;冥王星预测 248.95 年,真值 249.09 ± 0.05 → −2.9σ 接近(外推的代价)。
- 断言:数据 8 行与标签;T = 36000/L̇;pow/lin 核;木星牛顿因子 = 1/√(1+μ);正比 χ²_ν > 10⁵ 且不过关;幂律 n、C 与 scipy 一致且过关;BIC 差 > 10⁶;牛顿修正不降 χ²;n 越界不过关;两颗胶囊 3σ 内。
