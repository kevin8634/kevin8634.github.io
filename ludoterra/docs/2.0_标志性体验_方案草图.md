# 觉弈 Ludoterra 2.0 · 标志性体验方案草图(待王磊选定,未开发)

**推荐 A:「心之透镜」Mind Lens** —— 一问:「同一件事,为什么你和别人看到的不一样?」

**画面**:电影写实的黄昏城市街角(3D 程序生成,暖金逆光、体积光、浅景深),镜头前悬着一枚**等身高的琥珀色玻璃人脑**——觉弈图腾「金色人脑侧影」的立体版。r186 MeshPhysicalMaterial:透射+色散+厚度着色+薄膜虹彩;ACES/AgX 色调、轻颗粒。学习者**透过这颗玻璃脑看世界**:街景经它折射后才进入眼睛。脑内有 8 束光丝(八域),点亮过的关卡越多,玻璃越澄澈。无棋盘棋子(符合 §5.5)。

**改规则(七律②)**:三枚「透镜旋钮」就是三种偏差的曲率——①**损失放大**(厌恶损失:同样 100 元,失去那侧被放大 2 倍左右);②**近大远小**(现时偏好:明天的奖励被拉近放大,十年后的缩成一点);③**只见同色**(确认偏误/信息茧房:与你立场同色的光透过,异色被玻璃吸收)。拧一下,街景里的价签、时钟、新闻屏实时变形;拧回零,世界恢复真实比例。数值取自 1.0 已用关卡(sunk/compound/cocoon)的同一参数,不另造结论。

**三幕(每幕 ≤1 屏文字,七律⑤)**:①**看见透镜**:先给一个默认偏差组合,让学习者自己找出「哪里被扭曲了」。②**换一双眼睛**:一键借用另一个年龄段/另一种立场的透镜看同一条街,两画面分屏对照(接 lt.prisoner 信任、lt.cocoon 信息茧)。③**破茧**:学习者自己把三枚旋钮调到「我愿意的样子」(不是零,也没有标准答案),玻璃脑裂开化作光之莲与蝴蝶,落进认知星盘成为第 11 颗星;向导只提问,不评判(七律④⑦)。

**声音(七律⑥)**:玻璃钟共鸣,音高由折射率驱动,偏差越大越失谐(拍频);拧回真实比例时和弦归正。默认关。

**一张总图 / 星桥(七律③)**:玻璃脑的 8 束光丝 = 八域,点亮状态读 gn:lt:*;「换一双眼睛」可通星桥 ps.truth(05 奇点前夜)与 ls.rhythm(04 生命源码)。

**零打扰(七律⑦)**:纯本地、无账号;不计分、不排名、不贴「你有偏见」标签;不收集立场数据(只存本机)。

**性能**:高=透射+色散+体积光+景深;中=无色散、透射半分辨率、无景深;低/无 WebGL/减少动态=静态双图对照(原图 vs 透镜图)+ 旋钮仍可用,功能不减。手机像素比 ≤1.5,页面隐藏暂停。全部程序生成,无新外部素材。

**估算**:约 3 个开发轮次(场景与透镜着色器 → 三幕交互 → 降级与自测)。

**备选 B「复利晶体」Time Crystal**:一问「每天多 1%,三十年后差多少?」桌面上一块电影写实的玻璃晶体随 30 年时间轴生长,复利/单利/每天少 1% 三种规则长成三种形状;改利率、改「中途停一年」,晶体当场断层。优点:直接延展 1.0 最强关 compound,画面极强;缺点:主题偏财富,覆盖八域窄。

**备选 C「玻璃小镇」Trust Town**:一问「为什么好人不一定吃亏?」雪夜玻璃小镇里 30 个玻璃小人反复交换,信任是彼此间的光丝;改「误会噪声」「原谅率」「记仇时长」,看小镇变暖或碎裂(重复囚徒困境,接 lt.prisoner⇄ma.nim)。优点:群体动态好看、星桥自然;缺点:30 个透射体手机性能压力最大。

**推荐 A**:唯一同时覆盖「自我·他人·世界」三层、并以「破茧」收束觉弈图腾的方案,也最贴「认知觉醒」本义。
