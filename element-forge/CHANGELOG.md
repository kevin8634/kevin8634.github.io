# 元素工坊 Element Forge · 变更记录

## v0.3 · 2026-10-20(北京时间)
- 任务页改为 B1 沉浸舞台:四角熔金括弧、玻璃顶栏、半透明舞台面板,背后是随关卡切换的 Three.js 3D 场景。
  - stars:主序星 → 洋葱分层的大质量恒星 → 铁核心与聚变火花 → 超新星遗迹。
  - carbon:石墨三层蜂窝 → 数一数手 → 石墨层间滑动 → 金刚石晶格。
  - 过关时场景脉动一下;低档设备保持平面星空背景。
- 离线缓存:新增 /element-forge/sw.js,作用域只限本世界;页面先网络后缓存,资源先缓存后网络。
- 关卡玩法、进度键、声音规则不变。

## v0.2 · 2026-10-20(北京时间)
- 熔炉开场动画(约 7 秒,首次自动播放,可点任意处/Esc 跳过,设置里可重播):星尘塌缩 → 恒星点燃 → 穿越恒星洋葱层 → 四个氢核聚变 → 「元素工坊」烙印浮现 → 镜头拉出、HUD 从四角滑入。
- 首页改为 B1「沉浸舞台型」:全屏 Three.js 尺度镜七档(恒星/火星/紫甘蓝烧杯/金刚石晶格/甲烷分子/碳原子电子云/铁-56 原子核),滚轮、双指、方向键、刻度条切换,拖动旋转。
- 统一 HUD(§5.3.1):顶栏(返回创世计划/世界名/声音·全屏·设置)、四角熔金括弧、底部尺度镜刻度条、左侧任务与星桥抽屉、右侧向导气泡(每一档一个问题)。
- 元素起源周期表 3D 台面:点亮的元素升起并射出光柱,悬停显示元素卡,可切换俯视。
- 星桥:ef.stars ⇄ sh.where、ef.carbon ⇄ ma.bee 接通(任务知识笔记与首页抽屉);ef.stars ⇄ nv.stars 等待对岸。
- 性能三档:高 / 中(粒子减半)/ 低(回落 v0.1 平面版,功能不减);像素比桌面 ≤2、手机 ≤1.5;页面隐藏或滚出视口时暂停;尊重「减少动态效果」。Three.js r169 本地自带。
