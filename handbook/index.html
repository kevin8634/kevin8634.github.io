总门户:北斗七星与星桥

七个世界排成北斗七星,用跨学科的「星桥」连成一张总图。

游戏规则书

创世七律

  1. 一问一世界:任务以生活化问题命名,不以知识点命名。
  2. 规则可改:不是看世界,而是改世界。
  3. 一张总图:每个世界有 3D 知识图谱,并通过「星桥」相连。
  4. 向导只提问:分级提示,不直接给答案。
  5. 非文字优先:每关文字不超过一屏。
  6. 声音即规律:程序合成声景,由学科规律驱动。
  7. 零门槛零打扰:免费免注册,不刷题、不排名、不制造焦虑,未成年人隐私默认最高保护。

Chapter 09 / 第九章

咒语书:提示词的炼成

好的提示词像游戏里的咒语:目标、约束、验收标准、放权边界,四个元素齐了就能一次生效。以下是本次开发里王磊最出彩的几句「原咒语」,以及我们建议的「强化咒语」。

咒语 ①示意图与向导命名★★★★★

原咒语

「给我几份开发示意图,你做好向导的名字定位,以生物前沿名词为准……我希望开发出来的效果多以动画的形式表达,比如基因螺旋的旋转动画,一镜到底的放大效果……你给出建议以及对我的想法进行改良或纠错。」

强化咒语

「为生命源码出 3 张开发示意图(首页、任务页、向导家族)。向导以生物前沿名词命名,5 位以内。动画优先:基因螺旋旋转、一镜到底放大到碱基对。请先指出我想法里不合理的地方再给方案;只出方案和图,不写代码。」

为什么出彩 · 给了具体画面,还主动邀请纠错。

可补强 · 数量、交付物和「只出方案」的边界。

咒语 ②决策清单★★★★★

原咒语

「用『源码五灵』替换章鱼博士和蝙蝠博士;动画技术改用 WebGL + Three.js;虚拟显微镜、实验台、草莓实验卡进入 M1;……遗传任务保留人类性状,保持真实,求知而非刻意隐瞒。」

强化咒语

保持「决策清单」格式,每条加编号,并加一句「以上全部确认,按此执行;未提到的项按你的建议」。

为什么出彩 · 一次拍板多项决策,还给出价值观,AI 可以直接执行。

可补强 · 编号便于回溯。

咒语 ③放权★★★★☆

原咒语

「这次你直接按你的想法来,要求就是希望足够吸引人,不要太简单。」

强化咒语

「开场动画这次由你全权设计。标准:8 秒内抓住人、可跳过、手机不卡、默认静音。做完直接上线,我真机看。」

为什么出彩 · 敢放权,反而得到了满意的开场。

可补强 · 把「吸引人」翻译成可检查的标准。

咒语 ④结构化反馈★★★★★

原咒语

「进入时动画很满意,不过缺乏音乐,下个版本补上。另外把一镜到底的指纹那部分动画放在进入生命图谱上方,按钮换一个效果酷炫的模块……你构思下然后设计出来。」

强化咒语

保持「先肯定 → 缺什么 → 放在哪个版本 → 换什么」的结构,结尾加「给我 2–3 个方向的效果图选」。

为什么出彩 · 反馈结构清楚,放进了版本节奏。

咒语 ⑤ · 选择题

「构思关于创世计划按钮内的创意……做好三个创意方向然后用图片展示给我,由我选择开发方向。」

为什么出彩 · 把开放问题变成选择题——人负责选择,AI 负责发散。王磊后来选了 C(全息北斗星盘)。

咒语 ⑥ · 风险规则

「开发任务时,每完成一个项目就先上传,注意额度使用,若即将耗尽要保留返回进度,网盘保存……避免开发一半工程文件无法交接。」

为什么出彩 · 提前设定风险规则,后来多次换账号都能无缝接手。

咒语 ⑦ · 验收基准

「比对 06_生命尺度图谱.jpg 的差异,需要再优化。」

为什么出彩 · 用效果图当验收基准,比「再好看一点」精确十倍。

Boss 战 · 可以更好的地方

「OK 继续」

说清继续哪一项、到哪里停。

「按你的建议执行」

列出你同意的是哪几条。

「继续迭代」→「停止」

先说清停的原因和要保留的进度。

咒语卷轴 · 六张可复制模板

T1 新世界立项

为【世界名·学科】出立项方案:核心隐喻一句话;3 个以问题命名的首批任务;向导家族(命名规则:___);主色;与哪些世界可架星桥。只出方案,不写代码。

T2 效果图选择

为【模块】出 3 个差异明显的创意方向,每个一张效果图 + 三句话说明(体验、技术难度、风险)。我选定后再开发。

T3 迭代反馈

本版【满意的地方】。需要改:1.___ 2.___。放进 v___。验收标准:与【效果图文件名】对照 / 手机 375 宽不遮挡 / 默认静音。

T4 放权授权

【模块】这次由你全权设计。硬标准:___。范围仅限【子目录】。自测通过后可直接上线,上线后告诉我版本号和额度。

T5 交接与额度

额度剩 ___% 时停下:写开发日志、打包工程、同步云盘、更新交接文档,并告诉我下一步从哪里接。

T6 总指挥同步

同步云盘与 GitHub 最新进度,以工程包为准,列出各世界线上版本、星历缺口和待我决定的事项,先汇报再改线上。

科学审校

专业 AI

独立复核内容;生命源码 v0.2 一次修订 32 处。

心法七条

  1. 人定方向,AI 定实现:愿景、取舍、价值观由人拍板;代码、动画、文档交给 AI。
  2. 效果图先行:先看图再写代码,改图的成本远低于改代码。
  3. 云盘是共同记忆:交接文档(HANDOFF)从 v1 写到 v3.14,任何新窗口读完就能接手。
  4. 唯一真源:代码只认 GitHub,文档只认云盘;推送前先拉最新版本、核对文件指纹。
  5. 小步快跑:一天六个版本,每版都能上线、能回滚。
  6. 授权有边界:可以「自测通过直接上线」,但只限自己的子目录;根目录和别人的世界必须问。
  7. 额度也是资源:提前留出上线与归档的额度,避免「开发一半无法交接」。

Boss 战 · 踩过的坑

互相覆盖

多个窗口同时改总门户,差点互相覆盖 → 推送前拉最新 + 核对指纹。

旧页面卡住

根目录离线缓存(Service Worker)导致旧页面卡住 → 改为自毁版,保留到 2027-04-17,各世界只能缓存自己的子目录。

密钥外泄

密钥曾在聊天里出现 → 立即吊销更换,密钥只进保险库。

星历漏记

星历有时漏记 → 以工程包为准定期对账(10-21 补记元素工坊 v0.3)。

一句话

AI 让「做出来」变得便宜,于是「想清楚要什么」和「验证它是否真的帮到学习者」成了最值钱的能力。
